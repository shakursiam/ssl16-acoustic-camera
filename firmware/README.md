# SSL-16 Firmware Architecture & Implementation Notes

> [!NOTE]  
> **Firmware will be added in a later revision.** This directory contains the hardware-software interface specification, flashing instructions, and driver bring-up guidelines for the SSL-16 acoustic camera.

---

## 1. Programming and Debug Interface

The SSL-16 board utilizes the **ESP32-S3-WROOM-1-N8R8** microcontroller (U5), featuring native USB-Serial/JTAG on `GPIO19` (USB D−) and `GPIO20` (USB D+):

- **Primary Interface:** Direct programming and debugging over native USB-C port `J2`. No external USB-UART bridge IC is needed.
- **Manual Bootloader Entry:**
  1. Press and hold the **BOOT** button (`SW4` / `IO0`).
  2. Tap the **EN** / Reset button (`SW3` / `CHIP_PU`).
  3. Release the **BOOT** button (`SW4`).
- **UART Header (J3):** An auxiliary 4-pin 2.54 mm header is provided on the board (`TXD0`, `RXD0`, `GND`, `3V3`) for hardware UART console logging or automated factory flashing.

### Development Environment Configuration

#### Arduino IDE / PlatformIO
- **Board:** `ESP32S3 Dev Module`
- **USB CDC On Boot:** `Enabled` (routes `Serial` prints over native USB)
- **USB DFU On Boot:** `Disabled`
- **Upload Mode:** `USB-OTG / CDC`
- **Flash Size:** `8MB` (N8)
- **PSRAM:** `OPI PSRAM` (R8 - Octal SPI PSRAM)
- **Flash Mode:** `QIO` (or `OPI` depending on framework)

#### ESP-IDF (v5.x+)
- `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`
- `CONFIG_SPIRAM_MODE_OCT=y` (Octal PSRAM enabled)
- `CONFIG_SPIRAM_TYPE_AUTO=y`

## 2. I2S / TDM Audio Interface Architecture

The ESP32-S3 acts strictly as an **I2S / TDM Slave** receiver:

- **BCLK (Bit Clock):** `GPIO6` (routed from buffer `U10` output `Y3`). Frequency = **12.288 MHz**.
- **FSYNC (Frame Sync / Word Select):** `GPIO7` (fly-by trace from controller `U4`, AC terminated with `R30=51 Ω` + `C54=100 pF`). Frequency = **48 kHz**.
- **Data In (SDIN):** `GPIO13` (routed from target `U1` SDOUT via `R24=33 Ω`).
- **Frame Format:** TDM mode, **16 channels / slots**, **16 bits per slot** (256 BCLK cycles per frame).
- **Short Frame Sync:** PCM Short Frame (1 BCLK pulse width at frame start).

### ESP-IDF I2S TDM Configuration Guidelines *(To be verified at bring-up)*
```c
// Example ESP-IDF v5.x I2S TDM slave configuration structure
i2s_chan_config_t chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_0, I2S_ROLE_SLAVE);
i2s_chan_handle_t rx_handle;
i2s_new_channel(&chan_cfg, NULL, &rx_handle);

i2s_tdm_config_t tdm_cfg = {
    .clk_cfg = {
        .sample_rate_hz = 48000,
        .clk_src = I2S_CLK_SRC_DEFAULT,
        .ext_clk_freq_hz = 0,
        .mclk_multiple = I2S_MCLK_MULTIPLE_256,
    },
    .slot_cfg = {
        .data_bit_width = I2S_DATA_BIT_WIDTH_16BIT,
        .slot_bit_width = I2S_SLOT_BIT_WIDTH_16BIT,
        .slot_mode = I2S_SLOT_MODE_STEREO,
        .slot_mask = I2S_TDM_SLOT0 | I2S_TDM_SLOT1 | I2S_TDM_SLOT2 | I2S_TDM_SLOT3 |
                     I2S_TDM_SLOT4 | I2S_TDM_SLOT5 | I2S_TDM_SLOT6 | I2S_TDM_SLOT7 |
                     I2S_TDM_SLOT8 | I2S_TDM_SLOT9 | I2S_TDM_SLOT10 | I2S_TDM_SLOT11 |
                     I2S_TDM_SLOT12 | I2S_TDM_SLOT13 | I2S_TDM_SLOT14 | I2S_TDM_SLOT15,
        .ws_width = 1,                 // PCM short frame: 1 BCLK pulse width
        .ws_pol = false,               // FSYNC polarity
        .bit_shift = true,             // 1-bit delay per standard I2S/TDM
        .left_align = false,
        .big_endian = false,
        .bit_order_lsb = false
    },
    .gpio_cfg = {
        .mclk = I2S_GPIO_UNUSED,
        .bclk = GPIO_NUM_6,
        .ws   = GPIO_NUM_7,
        .dout = I2S_GPIO_UNUSED,
        .din  = GPIO_NUM_13,
        .invert_flags = {
            .mclk_inv = false,
            .bclk_inv = true,          // Sampling on falling edge may be required; TO VERIFY
            .ws_inv   = false,
        },
    },
};
i2s_channel_init_tdm_rx_mode(rx_handle, &tdm_cfg);
```

### Known Timing & Clock Considerations
- **bclk_inv Setting:** Depending on the setup and hold margin between ADC output change and ESP32 sampling, `bclk_inv = true` may be necessary to sample on the appropriate BCLK edge.
- **ESP-IDF Clock Divider Limit:** In slave mode, ESP-IDF internal APLL clock generation requirements may constrain the sampling rate if external MCLK is generated by ESP32 internal PLL. Because SSL-16 uses an external Abracon 24.576 MHz XO (`Y1`) driving the TDM controller (`U4`), the ESP32 receives true synchronous clocks on `IO6` and `IO7`.
- **Fallback Mode:** If the 12.288 MHz BCLK rate experiences jitter or DMA overruns on early ESP-IDF versions, the ADCs can be reconfigured to $f_s = 24\text{ kHz}$ ($\text{BCLK} = 6.144\text{ MHz}$) as a conservative fallback test.

## 3. I2C Control Bus & Sequencing

- **Pins:** `SCL` on `GPIO9`, `SDA` on `GPIO8`.
- **Pull-ups:** `2.2 kΩ` onboard resistors (`R17`, `R18`) tied to `+3V3`.
- **Clock Speed:** 100 kHz standard mode or 400 kHz fast mode.
- **Connected Peripherals:**
  - `0x4C`: TLV320ADC5140 `U1` (ADC-1, Target, slots 0–3)
  - `0x4D`: TLV320ADC5140 `U2` (ADC-2, Target, slots 4–7)
  - `0x4E`: TLV320ADC5140 `U3` (ADC-3, Target, slots 8–11)
  - `0x4F`: TLV320ADC5140 `U4` (ADC-4, Controller, slots 12–15)
  - `0x48`: TMP112 Temperature Sensor (`U9`)
- **Audio Capture Best Practice:**
  - Run I2C setup at system initialization.
  - **Avoid continuous I2C polling during high-speed audio acquisition:** Reading `U9` (TMP112) or querying ADC registers while DMA audio capture is running can inject switching noise into the shared analog/digital power rail or trigger bus contention. Poll temperature only between capture bursts.

## 4. Hardware Shutdown Line (SHDNZ)

- **Control Pin:** `GPIO11`
- **Circuit:** 100 kΩ pull-down resistor (`R31`) holds all four ADCs in hardware power-down state upon power-up.
- **Initialization Sequence:**
  1. Boot MCU with `GPIO11` driven `LOW` (or floating with internal pull-down).
  2. Stabilize all power supplies (+5V, VSYS, +3V3, 3V3A).
  3. Assert `GPIO11` `HIGH` (3.3V) to wake up `U1`–`U4`.
  4. Wait $\ge 1\text{ ms}$ for internal ADC voltage references and charge pumps to stabilize.
  5. Send I2C configuration commands to target ADCs (`U1`–`U3`).
  6. Send I2C configuration command to controller ADC (`U4`) last (starts BCLK and FSYNC clocks).

## 5. Storage (microSD 4-bit SDMMC)

- **Interface:** Native ESP32-S3 SDMMC peripheral in 4-bit bus mode.
- **Signals:**
  - `IO5`: `SD_CLK`
  - `IO4`: `SD_CMD`
  - `IO18`: `SD_D0`
  - `IO16`: `SD_D1`
  - `IO15`: `SD_D2`
  - `IO21`: `SD_D3`
  - `IO14`: `SD_CD` (Card Detect, active-low with 10 kΩ pull-up `R602`)
- **Activity LED:** `D601` (Green 0402 LED driven via `R601=2 kΩ` from `SD_D0` line).
